# WhatsApp Bot Project

This repository contains the source code for a WhatsApp Bot project. The project is developed incrementally and linked directly to each related commit or tutorial video to make tracking the development history easier.

---

## Project Summary

The goal of this project is to build a WhatsApp bot using Node.js. Each part of the repository represents a stage of feature integration and the basic application structure.

---

## Key Features

* Initialize connection with the WhatsApp server.
* Handle session management and basic authentication.
* Process incoming messages and basic command flow.

---

## Requirements

Before running this project, ensure your system has the following installed:

* Node.js (LTS version recommended)
* npm / pnpm / yarn
* Git

---

## Installation & Usage Guide

1. **Clone the repository**
   git clone https://github.com/xiryuudev/youtubeVideos.git
   cd youtubeVideos
2. **Install dependencies**
   npm install
3. **Run the application**
   npm start
